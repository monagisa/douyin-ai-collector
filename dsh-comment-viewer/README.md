# dsh-comment-viewer —— 把「评论分析台」嵌进 DSH

在 **DeepSeek Harness Web 界面**里直接看抖音评论的交互词云 + 评论表，不用再下载 HTML、也不用另开浏览器标签页。左侧栏「插件」组里会多一个 **评论词云** 入口，点开就是完整分析台。

数据来自本地已导出的 `douyin-comments-*.json`（抖音采集插件 / 浏览器扩展导出的文件），插件自动扫描并载入最新的那份。

分词与 `comment-viewer` 同源：抖音表情 `[憨笑]` / `[悲伤]` 这类方括号标签在分词前剥离，纯表情评论不产生关键词（v0.1.x 起；
对应采集插件 v0.5.32 的修复）。

## 安装

```powershell
dsh plugin --profile desktop add D:\dycopy\dsh-comment-viewer
```

装完**重启 DSH**（关闭再打开，或重启 `dsh` 进程）即可在左侧栏看到「评论词云」。

## 用起来

1. 打开左侧栏 **评论词云**；
2. 页面右上角会列出本地所有导出文件（按时间倒序），**默认自动载入最新的一份**；
3. 换一份：右上角下拉选择；新采集了数据：点「刷新列表」；
4. 点「清空」只清掉已载入的评论；右上角下拉框**仍然是磁盘上的文件列表**（52 份都在），只是选择退回「请选择要查看的导出文件…」，挑一份就重新载入，不用先刷新；
5. 悬停词看样例句、点词看全部评论、点昵称跳抖音主页、点「打开原视频」跳视频页。

## 删除接口与重启（v0.1.8 ~ v0.1.9）

- 批量删除走服务端 `POST /api/delete`，这个接口是**插件服务端代码**的一部分，只在 DSH 启动时加载；
  所以升级插件后如果没重启 DSH，「管理记录」里会显示：
  `当前 DSH 还在跑旧的服务端代码，重启 DSH 后才能删除记录（现在什么都不会删）`，删除按钮置灰。
- 重启 DSH 后按钮恢复，勾选 → 点「删除选中」即可（会弹确认框，真删磁盘文件、不可恢复）。
- 老进程下前端不再抛 `Unexpected end of JSON input`：响应按文本读、JSON 解析失败就降级成上面的提示。

## 清空与下拉（v0.1.7）

- 「清空」持久记忆（`localStorage['cw.embed.v1']`），刷新/切会话不会被自动装回来；
- 右上角「管理记录」：勾选多条导出记录批量删除（真删磁盘文件，服务端 `POST /api/delete` 只允许删允许目录里的 `douyin-comments-*`）；
- 评论表右上角 **「导出 CSV」/「导出 JSON」**（v0.5.42，导当前筛选结果）
- 词云面板与右侧关键词面板高度对齐。

- 「清空」会**持久记住**：被清空的导出文件记在 `localStorage['cw.embed.v1']`，刷新页面/切会话后它不会回到下拉里、也不会被自动载入；
- 需要时点右上角「找回已清空的 N」把列表恢复（磁盘文件从未删除）；
- 从未清空过时，打开页面会自动载入最新一份导出；清空过则停在下拉占位、由你自选。

- 「清空」只清已载入的评论；同时把**当前载入的那条文件**从右上角下拉里移除（其余文件保留，选择退回「请选择要查看的导出文件…」）；
- 磁盘文件不会被删除，点「刷新列表」重新扫描即可再选；
- 空状态「还没有数据」只在词云面板内居中显示，不再覆盖右侧栏。

- 载入/切换导出文件时显示**骨架屏**（KPI 灰条 / 词云散块 / 关键词 8 行 / 表格 8 行骨架），加载完成即替换；
- 空数据与有数据布局一致（右栏与评论表始终在位，只把内容降透明度），切数据不重排；
- 右下角与右上角的下拉均为磁盘文件列表；「清空」只清已载入评论，文件列表保留、选择退回「请选择要查看的导出文件…」。

## 数据目录（自动扫描）

| 目录 | 说明 |
| --- | --- |
| `<当前工作目录>/douyin-comments/` | DSH 采集插件 `douyin_comments` 的默认输出目录 |
| `~/.dsh/douyin-collector/out/` | 采集插件 / 扩展的全局默认输出目录 |
| 环境变量 `DSH_COMMENT_VIEWER_DIRS` | 额外目录，分号分隔，如 `D:\a;D:\b` |

只读：插件只列出并读取上述目录里的 `douyin-comments-*.json`，不写任何文件；`api/load` 会校验路径必须落在允许目录内（越权返回 403）。

## 结构

```
dsh-comment-viewer/
├─ package.json          # dsh.bundle.patch + dsh.client.platform=web
├─ cordis.patch.yml      # 注册 comment-viewer 到 profile
├─ src/index.mjs         # 服务端：静态托管 app/ + api/list + api/load
├─ src/client.js         # 客户端：侧栏 tab / 主区域 slot 注册（iframe 内嵌）
└─ app/                  # 评论分析台本体（index.html / styles.css / app.js）
```

`app/` 是 `D:\dycopy\comment-viewer\` 的嵌入式副本，改那边之后把三个文件复制过来即可。

## 限制

- 只在 DSH **Web** 界面可用（`dsh.client.platform=web`）；
- 页面在 iframe 里，词云的悬浮框不会超出 iframe 边界（正常使用不受影响）；
- 「打开导出目录…」在嵌入模式下隐藏（浏览器选目录对服务端文件没意义），改用右上角下拉 + 刷新列表。
